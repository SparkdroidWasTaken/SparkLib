# SparkLib

A from-scratch JavaScript library for machine learning, reinforcement learning, and many others.
Built for control, hackability, and fast experiments.

> Work in progress. V1 will include targets neural networks, optimisers, neuroevolution, DQN
> and autoencoders.

## Install

```
npm install github:SparkdroidWasTaken/SparkLib
```

## Usage

```js
import { sigmoid, relu, Dsigmoid } from 'sparklib';

console.log(sigmoid(0)); // 0.5
```
## Development

```
npm test        # run tests
npm run build   # build dist/
```
